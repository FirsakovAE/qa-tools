# Автозапуск (Auto Run)

> **Только режим расширения (Chrome / Edge).** Блок **Auto Run** в **Options → General** не показывается в **автономном (standalone)** запуске: у закладки нет фонового процесса расширения, который решал бы, на каких вкладках автоматически показывать панель.

**Auto Run** задаёт, при каких сайтах в режиме **оверлея** на странице **сама появляется** компактная точка входа (pill) в инспектор. Это не то же самое, что чёрный список **компонентов** во вкладке Props — здесь речь только о **адресах сайтов** (origin: схема, хост, порт). Под заголовком текст **Enable auto run application**. Единственный флажок — **Enable whitelist mode**. Отдельного выключателя списков нет.

---

## Общая логика

Правила смотрят на **origin** страницы (схема, хост, порт; путь не учитывается). Подсказка поля: `e.g. https://app.example/ or *localhost*`.

Полный URL `http` или `https` сравнивается по origin, без учёта регистра. Путь отбрасывается. Шаблон со `*` сопоставляется со всем origin, без учёта регистра: `*` — любой фрагмент, и шаблон должен покрыть origin целиком. Шаблон без `*` и без схемы должен совпасть со всем origin, поэтому `localhost` не совпадает с `http://localhost:5173`. Нужен шаблон `*localhost*`.

Пустой ввод и шаблон, который уже есть в этом списке, игнорируются без сообщения. Пустые списки ничего не ограничивают, пока в них нет строк (или не включён режим белого списка ниже).

Панель оверлея по-прежнему не появится на страницах, которые расширение считает **статическими** без Vue (отдельная проверка). От этого ограничения списки сайтов не освобождают — см. **всплывающее окно** расширения ниже.

---

## Site Blacklist (чёрный список сайтов)

Таблица **Site Blacklist** — адреса и шаблоны, на которых **автоматически не показывать** точку входа в инспектор.

- Поле и **Add**, либо Enter. Колонки **Name** и **Added**. **Added** — только дата.
- Пустой список: **No site in blacklist**.
- Клик открывает **Site Blacklist Details**. Меню — **Edit** и **Delete**.
- **Edit** — поле **Pattern** (подсказка **Origin pattern**). **Save** недоступна, пока поле пустое. Такой же шаблон у другой строки игнорируется. **Added** в карточке — дата и время. Назад или Escape закрывает карточку.
- Если текущий origin совпал с любой строкой, автозапуск оверлея на этой вкладке выключен.

Чёрный список **можно комбинировать** с белым: сначала проверяется белый список (если он активен и не пуст), затем чёрный.

## Site Whitelist и «whitelist mode»

Переключатель **Enable whitelist mode** показывает **Site Whitelist**. Предупреждение на блоке: **When the whitelist is not empty, the application will only run when the page origin (scheme, host including www, port) matches a pattern.**

- Пока **белый список пуст**, режим по сути никого не ограничивает: работают только правила **чёрного** списка (если он заполнен).
- Как только в белом списке есть **хотя бы одна** запись, автоматический показ оверлея разрешён **только** на тех origins, которые **совпали** с одной из записей белого списка. Все остальные сайты для автозапуска считаются запрещёнными — до тех проверок, пока не сработает чёрный список поверх уже разрешённых.
- Пустой список: **No site in whitelist**. Строка открывает **Site Whitelist Details**. Добавление, правка и удаление такие же, как у чёрного списка. Такой же шаблон в этом списке игнорируется.

Иными словами: **непустой белый список** сужает круг «где можно», **чёрный список** вычитает из него отдельные адреса.

## Всплывающее окно расширения (popup): «запасной выход»

![Всплывающее окно](/screenshots/popup.jpg)

У иконки Vue Inspector в панели браузера есть **маленькое окно** с двумя действиями (на английском в интерфейсе: **Forced Launch** и **Reset Settings**).

**Forced Launch** — принудительно вставляет панель инспектора на **текущей активной вкладке**, **игнорируя** правила Auto Run (чёрный/белый список) и эвристику «статический сайт». Нужна, если вы сами настроили списки так, что pill больше нигде не появляется, а открыть **Options** неоткуда.

**Reset Settings** — **полный сброс** сохранённых пользовательских настроек расширения (включая Auto Run, оформление, избранное и прочее). [Options → AI](/ru/ai/settings) остаётся. Это крайняя мера, если вы «перекрыли» себе доступ настройками: после сброса списки и режимы возвращаются к состоянию по умолчанию, и панель снова можно открыть обычным способом. Используйте осознанно: восстановить прежний профиль без резервной копии нельзя.

Совет: если пользуетесь жёстким белым списком, держите в нём хотя бы адрес страницы, с которой вы обычно заходите в Options, либо помните про **Forced Launch** и **Reset Settings** в popup.
