# Параметры обновления

В **Options → General** ниже блока визуальных настроек **Customize** расположены два связанных с данными блока: **Search Parameters** (параметры поиска) и **Auto Refresh** (автообновление дерева и сторов). Они сохраняются в общем профиле настроек вместе с остальными опциями (см. [Менеджер настроек](/ru/options/settings_management)).

---

## Search Parameters

Здесь задаются общие правила текстового поиска на вкладках **Props**, **Network**, **Pinia Stores** и **Logs**. По умолчанию **300** мс и **2** символа.

### Search Debounce (ms)

Задержка после остановки ввода, прежде чем запрос применится. У поля границы **100–1000**. По умолчанию **300**.

### Minimum Search Length

Минимум символов, с которого начинается новый фильтр. У поля границы **1–10**. По умолчанию **2**.

Более короткий непустой запрос новый поиск не запускает. Остаётся предыдущий результат, пока поле не очистят или запрос не достигнет минимума. Пустое поле показывает полный список. **Network** и **Logs** считают длину текста внутри двойных кавычек. **Props** и **Pinia Stores** считают всё поле, включая сами кавычки.

---

## Auto Refresh

**Enable auto refresh** по умолчанию выключен. **Refresh Interval** виден только пока флажок включён. Интервал по умолчанию — **5 seconds**. Варианты: **1 second**, **2 seconds**, **5 seconds**, **10 seconds**, **30 seconds**.

**Pinia Stores** заново запрашивает список сторов с этим интервалом, пока открыта эта вкладка и панель видна. Тик пропускается, если загрузка уже идёт. Скрытие панели останавливает таймер; показ запускает его снова, если флажок всё ещё включён.

**Props** обновляет дерево компонентов с этим интервалом, пока панель видна, и останавливается, пока она скрыта. Если за **5** секунд приходит **10** обновлений дерева, следующие обновления отбрасываются **10** секунд. В консоли строка `Props update flood detected, entering cooldown`. Отдельного переключателя нет. Смена флажка или интервала запускает второй таймер **Props**, который идёт, пока вы не уйдёте с вкладки **Props**, в том числе при скрытой панели.

**Network** этим таймером не обновляется.
