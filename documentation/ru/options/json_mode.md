# JSON Mode (режим просмотра JSON)

JSON во всём инспекторе — тела запросов и ответов во вкладке **Network**, тела в **Mock response**, снимки **Pinia**, данные компонента на **Props**, если содержимое распознаётся как JSON — открывается в **vanilla-jsoneditor**.

Переключателя Classic / Advanced нет. Сохранённые настройки со значением **Classic** читаются как этот редактор.

- **Два представления одного и того же JSON**: **Text** (код) и **Tree** (структура). Переключение — на панели редактора; последний выбор сохраняется (`json.mode`).
- **Режим Text**: форматирование (**Format** / **Compact**, где разрешено редактирование), **Undo / Redo**, поиск и копирование.
- **Режим Tree**: свёртка и развёртка узлов, хлебные крошки, контекстное меню узла и сортировка.

Тела **не в формате JSON** (XML, обычный текст и т.д.) по-прежнему открываются в одном текстовом виде с подсветкой Prism, где это поддерживается.
