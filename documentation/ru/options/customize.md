# Персонализация (Customize)

![Персонализация](/screenshots/Customize.jpg)

В **Options → General → Customize** собраны настройки внешнего вида основного окна инспектора: тема, фоновое медиа и параметры его отображения. Оформляется панель инструмента, а не открытый сайт.

---

## Расширение и Standalone: что отличается в Customize

Набор полей (**тема**, **файл / ссылка**, прозрачность, размытие, позиция, масштаб) **одинаковый**. Отличается то, **куда складываются локальные копии файлов** и **есть ли учёт общего лимита по размеру**.

| | **Расширение (Chrome / Edge)** | **Автономный режим (Standalone)** |
|---|--------------------------------|-------------------------------------|
| **Где хранятся выбранные файлы** | Копии медиа пишутся в **IndexedDB** контекста расширения (отдельные хранилища под обои и прочие сохранённые файлы). | Медиа для оформления уходит в **единое локальное хранилище** приложения (центральное хранилище с лимитом). |
| **Лимит по объёму** | Отдельного лимита «N МБ на медиа» в приложении **нет**; реальное ограничение — **квота IndexedDB / хранилища** в рамках профиля браузера для расширения. | **Жёсткий лимит 30 МБ** на **суммарный** размер медиа в хранилище standalone: при добавлении проверяется новый суммарный объём; при превышении сохранение **блокируется** (ошибка вида «Media limit exceeded»). |
| **Индикатор заполнения** | Счётчик «X МБ / 30 МБ» не показывается. | Под **Saved Files**: **N.N MB / 30 MB**. Полоса жёлтая с **70%** и красная с **90%**. |

Фон по **URL** в обоих режимах не «весит» в локальном медиа-квотинге инспектора так же, как загруженный файл — но для офлайн и предсказуемости обычно удобнее сохранять файл локально в пределах квоты (в Standalone — с учётом **30 МБ** суммарно).

## Тема

![Персонализация: селекторы](/screenshots/Customize_selectors.jpg)

Кнопка-иконка рядом с именем картинки переключает тему инспектора. По умолчанию тема тёмная. Подсказка: **Switch to light theme** или **Switch to dark theme**.

---

## Фон (Image)

Блок **Image** задаёт фон панели. Имя текущего фона стоит рядом с **Change background**. Если ничего не выбрано, это **Night Forest**. Источники — **File** и **Link**:

- **Файл** — локальный ресурс. Можно выбрать через **Browse** или из списка ранее сохранённых копий (расширение: IndexedDB; standalone: единое хранилище с лимитом **30 МБ** — см. таблицу выше). Про наборы настроек — [Менеджер настроек](/ru/options/settings_management).
- **Ссылка** — указать URL медиа по ссылке.

Поддерживаются **статичные изображения**, анимированные **`GIF`** и фоновое видео **`MP4`**.

---

## Параметры отображения фона

| Параметр | Назначение |
|----------|------------|
| **Image Opacity** | **0–0.50**, шаг **0.01**. По умолчанию **0.20**, на экране два знака после запятой. |
| **Blur** | **0–200** px. По умолчанию **34**. |
| **Position X** / **Position Y** | **0–100%**. По умолчанию **22** и **30**. |
| **Scale** | **100–200%**. По умолчанию **100**. |

Ползунки оставляют фон читаемым. Отдельного шума нет.

## Сохраненные файлы

![Предпросмотр файла](/screenshots/File_preview.jpg)

Раздел **Saved Files** на странице **General** хранит локальные копии медиа для повторного использования.

Они используются в нескольких сценариях:

* выбор фонового файла в **Customize**;
* файловые поля **Form-data** при breakpoint во вкладке **Network**;
* другие места, где инспектору нужен повторный выбор уже сохранённого файла.

Правила хранения для **расширения** и **standalone** совпадают с таблицей выше: различаются тип хранилища и доступный объём.

### Список файлов

Под заголовком написано **Files saved from breakpoint form-data editing for quick reuse.**

Колонки **Name** и **Size**. Меню строки — **Edit** и **Delete**. **Edit** заменяет файл. Клик открывает **File Preview** (имя, размер, тип и превью для картинки, аудио, видео, текста или PDF). У файла Office показан тип, кнопки **Open** и **Download**. **Add new file** стоит под строками и принимает несколько файлов. Файл с тем же **именем** и **размером** пропускается без сообщения.

В **расширении** таблица — только **Saved Files**. В **standalone** сначала обои, затем файлы breakpoint. Полоса объёма над таблицей есть только в standalone.

**Auto-save new files selected via Browse** по умолчанию выключен.

Если опция включена, файл сохраняется в **Saved Files**, когда:

* он выбран через **Browse**;
* ещё нет записи с той же парой **имя + размер**.

Это используется, например, при редактировании **Form-data** в breakpoint во вкладке **Network**.

### Использование в Form-data

При выборе файла из списка в редакторе **Form-data** в черновик записывается служебная ссылка вида **`__fileId:`…**.

При применении изменений внедрённый сценарий использует этот идентификатор, чтобы подставить реальные байты файла в запрос.

Подробности — в разделе [Подмена трафика](/ru/network/traffic).
