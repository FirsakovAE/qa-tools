# AI-ассистент

Вкладка **AI assistant** стоит после **Logs**. В шапке самой вкладки написано **AI**. Ассистент отвечает на вопросы по записанным логам и странице. Как прикрепить запрос, компонент, стор или событие лога, описано на страницах этих вкладок.

Подключение, что ассистенту можно читать, маскирование, стиль и список моделей лежат в [Options → AI](/ru/ai/settings). Здесь описан сам чат.

## До первого вопроса

Без ключа API вкладка пишет **Connect an AI provider** и предлагает **Connect in Options → AI**. В тексте назван бесплатный ключ Gemini или OpenRouter.

С ключом, но без подтверждения, вкладка пишет **Data sent to OpenRouter** или **Data sent to Gemini**:

* вопросы, выжимка записанных логов, данные событий и код страницы, который ассистент запросит;
* токены, пароли, ключи API и другие значения из списка маскирования AI заменяются на `[MASKED]` до отправки; что ассистенту можно читать, задаётся в **Options → AI → Agent access**;
* бесплатные модели могут сохранять запросы и использовать их для обучения.

**I understand** подтверждает. **Review access** открывает **Options → AI → Agent access**. До этого поле ввода недоступно и показывает **Connect a provider to ask questions**.

После подтверждения пустой чат предлагает четыре примера вопросов. Клик по примеру отправляет его.

## Верхняя панель

| Элемент | Поведение |
| ------- | --------- |
| Провайдер | **OpenRouter** или **Gemini** |
| Модель | Видна, когда ключ задан и список моделей загружен. Первой идёт **Auto**: *free models, switches on limits*. Дальше группы **Recommended** и **Added**. У модели может быть пометка **paid**, статус, **unstable** и сколько запросов к ней было сегодня |
| **Checking models...** | Пока список загружается |
| **Models failed to load, retry** | Если список не загрузился. В подсказке — текст ошибки |
| Обновление | Подсказка **Check which models are available** |
| Настройки | Подсказка **AI settings: connection, access, masking, style, models**. Открывает **Options → AI** |
| **New chat** | Подсказка **New chat**. Недоступна, когда чат пуст и ассистент простаивает. Очищает разговор. Пока инспектор открыт, разговор сохраняется и после переключения вкладок. Перезагрузка страницы начинает пустой чат |

Список моделей скрыт, пока нет ключа и загруженных моделей.

## Вопросы

Подсказка поля — **Ask AI**. С прикреплёнными плашками — **Ask about the attached data**.

**Enter** отправляет. **Shift+Enter** переносит строку. Подсказка кнопки отправки: **Send (Enter; Shift+Enter for a new line)**. Для отправки нужен текст или хотя бы одна плашка. Если отправить только плашки, ассистента просят объяснить прикреплённые данные и указать, что в них не так. Плашка остаётся у вопроса; **×** снимает её до отправки.

Пока ответ идёт, кнопка — **Stop**.

Под полем, когда чат готов:

* OpenRouter: **Today: N of M free OpenRouter requests (counted in this browser). Each assistant step is one request.** **M** — лимит, который сообщил провайдер, или **50**, если он его не сообщил. В режиме **Auto** второй фразой идёт, сколько моделей пропущено из-за квоты или недоступности.
* Gemini: **Today: N Gemini requests. Daily limits depend on the model and your Google AI Studio project.** Та же фраза про **Auto** может идти следом.

**Auto** можно выбрать, только если в списке есть модель без пометки paid. Для ручной модели она должна быть выбрана, иначе поле вопрос не примет.

## Ответы

Вопрос справа. Ответ слева, с именем модели и числом запросов этого ответа.

**Copy** у сообщения копирует его текст. Подсказка становится **Copied**, либо появляется уведомление **Could not copy to the clipboard**. У блока кода в ответе своя кнопка копирования.

Ссылка `#N` в ответе открывает это событие на вкладке **Logs**. Если его уже нет, уведомление пишет **The event is no longer in the logs**.

**Try again** у последнего ответа отправляет тот же вопрос ещё раз. Кнопка недоступна, пока идёт ответ или чат не готов.

Если выбранная модель упала по причине, которая относится именно к ней, у ответа появляется **Switch to Auto and try again**. Это включает **Auto** и отправляет вопрос снова.

Пока запуск ждёт разрешения, чат спрашивает **Allow the assistant to read logs?**, **… page code?** или **… the live page?**. Варианты: **Allow**, **Allow in this chat** и **Deny**. **Allow in this chat** действует до **New chat**.

Неудачный ответ показывает ошибку в карточке. **Provider message** раскрывает текст, который вернул провайдер.
