# AI-ассистент

Вкладка **AI assistant** стоит после **Logs**. В шапке самой вкладки написано **AI**. Ассистент отвечает на вопросы по записанным логам и странице. Как прикрепить запрос, компонент, стор или событие лога, описано на страницах этих вкладок.

Подключение, что ассистенту можно читать, маскирование, стиль и список моделей лежат в [Options → AI](/ru/ai/settings). Здесь описан сам чат.

## До первого вопроса

Без ключа API вкладка пишет **Connect an AI provider** и предлагает **Connect in Options → AI**. В тексте назван бесплатный ключ Gemini или OpenRouter, а также свой провайдер: OpenAI, DeepSeek, локальная модель (Ollama, LM Studio) или любой OpenAI-совместимый агент. См. [Свои провайдеры](/ru/ai/settings#your-own-providers).

С ключом, но без подтверждения, вкладка пишет **Data sent to OpenRouter** или **Data sent to Gemini**, а для своего провайдера — **Data sent to {имя} ({хост})**:

* вопросы, выжимка записанных логов, данные событий и код страницы, который ассистент запросит;
* токены, пароли, ключи API и другие значения из списка маскирования AI заменяются на `[MASKED]` до отправки; что ассистенту можно читать, задаётся в **Options → AI → Agent access**;
* OpenRouter и Gemini: бесплатные модели могут сохранять запросы и использовать их для обучения. Свой провайдер: что сервер локальный или что данные уходят на его хост по условиям этого сервиса; для удалённого адреса `http://` добавляется предупреждение, что ключ и данные идут без шифрования.

У OpenRouter и Gemini одно общее подтверждение. Каждый свой провайдер спрашивает своё. **I understand** подтверждает. **Review access** открывает **Options → AI → Agent access**. До этого поле ввода недоступно и показывает **Connect a provider to ask questions**.

После подтверждения пустой чат предлагает четыре примера вопросов. Клик по примеру отправляет его.

## Верхняя панель

| Элемент | Поведение |
| ------- | --------- |
| Провайдер | **OpenRouter**, **Gemini**, затем свои провайдеры по имени |
| Модель | Видна, когда ключ задан и список моделей загружен. Первой идёт **Auto**: *free models, switches on limits* (у своих провайдеров — *listed models, switches on errors*). Дальше группы **Recommended** и **Added**. У модели может быть пометка **paid**, статус, **unstable** и сколько запросов к ней было сегодня |
| **Checking models...** | Пока список загружается |
| **Models failed to load, retry** | Если список не загрузился. В подсказке — текст ошибки |
| Обновление | Подсказка **Check which models are available** |
| Настройки | Подсказка **AI settings: connection, access, masking, style, models**. Открывает **Options → AI** |
| **New chat** | Подсказка **New chat**. Недоступна, когда чат пуст и ассистент простаивает. Очищает разговор. Пока инспектор открыт, разговор сохраняется и после переключения вкладок. Перезагрузка страницы начинает пустой чат |

Список моделей скрыт, пока нет ключа и загруженных моделей.

## Вопросы

Подсказка поля — **Ask AI**. С прикреплёнными плашками — **Ask about the attached data**.

**Enter** отправляет. **Shift+Enter** переносит строку. Подсказка кнопки отправки: **Send (Enter; Shift+Enter for a new line)**. Для отправки нужен текст или хотя бы одна плашка. Если отправить только плашки, ассистента просят объяснить прикреплённые данные и указать, что в них не так. Плашка остаётся у вопроса; **×** снимает её до отправки.

Пока ответ идёт, кнопка — **Stop**.

## Прикрепление файлов

**+** рядом с полем открывает два пункта:

* **Text file** (TXT · LOG · JSON · HAR · MD · CSV · PDF): прикрепляет один или несколько файлов к следующему вопросу, как плашки с других вкладок. Файл не закрепляется за чатом: он уходит с вопросом, к которому прикреплён, а в следующих вопросах того же чата ассистент может прочитать его снова. **New chat** его сбрасывает. Файлы также можно перетащить на поле или вставить в него. До 64 МБ на файл. PDF: читается только текстовый слой; сканы страниц и файлы с паролем не принимаются.
* **Vue inspector Log**: экспортированный лог Vue Inspector. Он закрепляется за чатом: дайджест и инструменты логов читают его вместо живой записи до **New chat**.

Длинный вставленный текст (больше 4000 символов или 60 строк) становится плашкой **Вставленный текст N** и обрабатывается как файл. Более короткая вставка попадает в поле как обычно.

Небольшой файл (примерно до 2000 токенов) уходит ассистенту целиком. Файл больше не отправляется: ассистент получает его обзор (размер, структуру JSON, запросы и неуспешные запросы HAR, заголовки Markdown, колонки CSV, страницы PDF, первые строки и строки с ошибками лога) и инструменты для поиска по файлу, чтения его частей и запросов к JSON / HAR по пути. Так большой файл стоит только тех частей, которые нужны для ответа. Первый шаг ответа для такого файла пишет **(overview; content read with file tools)**. Подсказка плашки показывает формат, размер, число строк и оценку токенов.

Под полем, когда чат готов:

* OpenRouter: **Today: N of M free OpenRouter requests (counted in this browser). Each assistant step is one request.** **M** — лимит, который сообщил провайдер, или **50**, если он его не сообщил. В режиме **Auto** второй фразой идёт, сколько моделей пропущено из-за квоты или недоступности.
* Gemini: **Today: N Gemini requests. Daily limits depend on the model and your Google AI Studio project.** Та же фраза про **Auto** может идти следом.
* Свой провайдер: **Today: N requests to {имя} (runs on your server).** для локального или **(limits and billing are set by your account there)**, затем **Each assistant step is one request.** Та же фраза про **Auto** может идти следом.

Первый шаг ответа называет, куда ушли данные: для своего провайдера — **Sent to {имя} ({хост})**. При **Tools: No tools** вместо доступа к инструментам там написано **no tools with this connection**.

**Auto** можно выбрать, только если в списке есть модель без пометки paid. Для ручной модели она должна быть выбрана, иначе поле вопрос не примет.

## Ответы

Вопрос справа. Ответ слева, с именем модели и числом запросов этого ответа.

**Copy** у сообщения копирует его текст. Подсказка становится **Copied**, либо появляется уведомление **Could not copy to the clipboard**. У блока кода в ответе своя кнопка копирования.

Ссылка `#N` в ответе открывает это событие на вкладке **Logs**. Если его уже нет, уведомление пишет **The event is no longer in the logs**.

**Try again** у последнего ответа отправляет тот же вопрос ещё раз. Кнопка недоступна, пока идёт ответ или чат не готов.

Если выбранная модель упала по причине, которая относится именно к ней, у ответа появляется **Switch to Auto and try again**. Это включает **Auto** и отправляет вопрос снова.

Пока запуск ждёт разрешения, чат спрашивает **Allow the assistant to read logs?**, **… page code?** или **… the live page?**. Варианты: **Allow**, **Allow in this chat** и **Deny**. **Allow in this chat** действует до **New chat**.

Неудачный ответ показывает ошибку в карточке. **Provider message** раскрывает текст, который вернул провайдер.
