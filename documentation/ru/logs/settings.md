# Настройки логов

В **Options → Logs** собраны настройки вкладки [Logs](./general.md). Изменения применяются сразу.

---

## Search Settings

Режимы поиска вкладки **Logs** по умолчанию:

| Параметр | Где ищет |
| -------- | -------- |
| **Search by event name** | Заголовок, компонент, стор, URL (включён по умолчанию) |
| **Search by key** | Ключи в данных события и пути изменений |
| **Search by value** | Значения в данных события |

---

## Ignore list

Группы событий, добавленные через **Ignore** во вкладке **Logs**. События этих групп не записываются.

| Колонка | Содержимое |
| ------- | ---------- |
| **Type** | Тип события |
| **Event** | Ключ группы: запрос (метод и путь), компонент, стор и т.д. |
| **Added** | Дата добавления правила |

* **Log again** в меню строки снимает одно правило.
* **Log all again** снимает все правила.

Тот же список доступен через индикатор **ignored** на панели вкладки **Logs**.

---

## Export

Формат **Export Logs** и экспорта одного события:

* **JSON** — исходные события для повторного импорта или сторонних инструментов;
* **HTML** (по умолчанию) — статический отчёт, открывается в любом браузере и импортируется обратно.

Подробнее: [Экспорт и импорт](./export.md).

---

## Logs limits

Каждый тип событий — **кольцевой буфер**: при заполнении самые старые события перезаписываются. Бюджет памяти общий для всех типов.

### Events per type

| Тип | По умолчанию | Единица |
| --- | ------------ | ------- |
| **Network** | 500 | запросов |
| **Props changes** | 1 000 | событий |
| **Emits** | 1 000 | событий |
| **Pinia changes** | 1 000 | событий |
| **Store actions** | 1 000 | событий |
| **Navigation** | 200 | событий |
| **JS errors** | 200 | событий |

Допустимый диапазон: **10 – 20 000**. Число перед полем показывает, сколько событий этого типа хранится сейчас. Для **Network** лимит действует отдельно для событий **Send request** и **Receive response**.

### Data size

| Параметр | По умолчанию | Диапазон | Назначение |
| -------- | ------------ | -------- | ---------- |
| **Memory budget** | 64 МБ | 8 – 1024 МБ | Общий объём всех событий в буфере (приблизительный размер после сериализации) |
| **Max event size** | 512 КБ | 16 – 16 384 КБ | Крупные части события (снимки стора, аргументы, результаты) отбрасываются, сетевые тела обрезаются до этого размера |

Полоса под полями показывает текущее использование (**Used X of Y**); выше 90 % она становится оранжевой.

Значения вне диапазона приводятся к ближайшей границе. **Defaults** восстанавливает все лимиты.

## Data masking {#data-masking}

Значения маскируются **в момент записи события**, поэтому не попадают ни в интерфейс **Logs**, ни в экспорт, ни в импорт.

| Параметр | Назначение |
| -------- | ---------- |
| **Mask sensitive data** | Включает маскирование (включено по умолчанию) |
| **Mask token-like values in any text** | Маскирует **JWT**, учётные данные **Bearer** / **Basic** и номера карт внутри любой строки |
| Список **Key contains** | Ключи объектов, имена заголовков и параметров, содержащие эти фрагменты, маскируются |

Ключи по умолчанию: `password`, `passwd`, `pwd`, `secret`, `token`, `authorization`, `cookie`, `apikey`, `sessionid`, `privatekey`, `creditcard`, `cardnumber`, `cvv`, `cvc`, `ssn`, `otp`.

Сравнение ключей не учитывает регистр и разделители (`api_key`, `api-key` и `apiKey` — одно и то же). Фрагменты из **4 букв и короче** должны совпадать с целым словом, поэтому `pwd` или `otp` не маскируют посторонние ключи.

Свои фрагменты добавляются в поле под списком, удаляются через меню строки. **Default keys** восстанавливает список по умолчанию.

Замаскированные значения заменяются метками: `[MASKED]` — для значений чувствительных ключей, `[MASKED JWT]` и `[MASKED CARD]` — для токенов и номеров карт, найденных в тексте (номера карт проверяются алгоритмом Луна).
