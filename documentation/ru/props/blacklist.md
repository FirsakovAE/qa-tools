# Чёрный список компонентов (Props)

**Чёрный список** во вкладке **Props** — это набор **имён Vue-компонентов**, которые исключаются из дерева инспектора и не отображаются в таблице. Фильтрация применяется **до построения списка props**, поэтому скрытые компоненты не участвуют в обычном обходе дерева.

Общее описание вкладки Props: [Основные возможности](/ru/props/general).

Не путайте этот список с **чёрным списком сайтов** для **автозапуска** оверлея (настройки **General / Auto Run**): здесь фильтрация относится только к **именам компонентов**.

---

## Где добавить и убрать

Добавить компонент в чёрный список можно двумя способами.

* **Ignore by name** в меню строки добавляет текущее имя в **Blocked**. Пустое имя пропускается. Имя, которое уже есть в **Blocked** или **Allowed**, повторно не добавляется.
* **Options → Props → Component Blacklist** — список и карточка деталей описаны ниже.

---

## Blocked и Allowed

Список правил делится на два состояния.

* **Blocked** — совпавшее имя скрывается.
* **Allowed** — исключение. Имя, которое совпало с любым правилом **Allowed**, остаётся в списке, даже если его накрывает правило **Blocked**.

Правила **Allowed** ничего не делают, пока нет ни одного **Blocked**. Удаление строки полностью убирает правило.

### Component Blacklist в Options

Блок стоит после **Inspect Mode**. Подсказка поля: **Component name (supports wildcards: *Comp*)**. **Add** или **Enter** обрезает пробелы и добавляет строку в **Blocked**. Пустое значение: **Name cannot be empty**. Та же сохранённая строка уже в **Blocked** или **Allowed**: **This name is already in the blacklist**. Проверка дубликата учитывает регистр, поэтому `Foo` и `foo` — два правила; само сопоставление имён регистр игнорирует.

| Колонка | Что показывает |
| ------- | -------------- |
| **Component Name** | Сохранённый шаблон. |
| **Status** | **Blocked** или **Allowed**. Строки **Allowed** приглушены. |

Сначала идут все **Blocked**, затем **Allowed**, в порядке добавления. Меню строки (правый клик или **⋮**): **Allow** или **Block**, и **Delete**. Пустая таблица: *No components in blacklist*.

Клик открывает **Blacklist Details**: **Component Name** и **Status** (**Blocked** или **Allowed**). Кнопки **Edit** нет. **Назад** или **Escape** закрывают карточку. Если ничего не выбрано, панель пишет *Select an item to see details*. Если правило удалили при открытой карточке, она пишет *Item no longer exists*. Ниже **1000** px карточка закрывает список настроек, пока её не закроют.

Карточка не выбирает этот компонент на вкладке Props.

---

## Как сопоставляется имя

Сравнение выполняется по **имени компонента**, которое отображается в инспекторе.

* Если правило **не содержит** символов **`*`** или **`%`**, используется **точное совпадение** без учёта регистра.
* Символы **`*`** и **`%`** работают как шаблон подстановки произвольного фрагмента имени.

Например:

* `MyButton` — скрывает только компонент с точным именем **MyButton**;
* `Base*` — скрывает все компоненты, имя которых начинается с **Base**;
* `*Modal*` — скрывает все имена, содержащие **Modal**.

Для безымянных компонентов может использоваться внутреннее обозначение вроде **Anonymous**, если оно присутствует в дереве.

---

## Исключения и пересечения

Любое совпадение **Allowed** побеждает: имя остаётся видимым. Иначе любое совпадение **Blocked** его скрывает.

Широкое правило **Blocked** вместе с более узким **Allowed** оставляет исключение на экране. Перевод широкого правила в **Allowed** делает этот шаблон исключением для каждого подходящего имени.

---

## Когда применяется

Актуальный список правил используется при каждом обновлении дерева:

* при ручном **Refresh**;
* при автоматическом обновлении списка;
* при повторном открытии вкладки.

Если в таблице Props уже есть строки, правка в **Options** её обновляет. Пустой список подхватывает правила при следующем перестроении.

Пока правило **Blocked** скрывает имя, этот компонент нельзя выбрать в таблице и карточке.

---

## Практические советы

* Начинать удобнее с **точного имени** через контекстное меню строки.
* **Широкие маски** подходят для повторяющихся служебных компонентов, но требуют аккуратности.
* Чёрный список влияет только на **отображение в инспекторе** и не изменяет работу Vue-приложения.
